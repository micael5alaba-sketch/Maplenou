# Glossaire

Les mots utilisés dans le service client Maplenou et dans ce guide, expliqués simplement.

## Termes sur les tickets et les personnes

Ticket
:   Votre demande d'aide auprès du support Maplenou : une question, un incident ou un problème. Chaque ticket a un numéro unique.

Numéro de ticket
:   L'identifiant de votre ticket, par exemple `TKT-2026-00125`. Il est unique et n'est jamais réutilisé. Donnez-le quand vous parlez de ce ticket au support.

Demandeur
:   La personne qui crée le ticket : un client, un vendeur ou un livreur Maplenou.

Client
:   Une personne qui achète sur la place de marché Maplenou.

Vendeur
:   Une personne ou une entreprise qui vend sur la place de marché Maplenou.

Livreur
:   Une personne qui livre les commandes Maplenou.

Agent support
:   Un membre de l'équipe support Maplenou qui traite les tickets et vous répond.

Pris en charge par
:   Le nom de l'agent support à qui votre ticket est attribué. Tant qu'aucun agent n'est attribué, le ticket affiche <span class="ui">En attente d'attribution</span>.

Catégorie
:   Le type de demande : <span class="ui">Commande</span>, <span class="ui">Paiement</span>, <span class="ui">Livraison</span>, <span class="ui">Vendeur</span>, <span class="ui">Compte</span>, <span class="ui">Retour / remboursement</span> ou <span class="ui">Autre</span>. Un ticket a une seule catégorie.

Référence de commande ou de livraison
:   La commande (<span class="ui">Commande concernée</span>) ou la livraison (<span class="ui">Livraison concernée</span>) liée au ticket. Elle est facultative et doit faire partie de vos propres commandes ou livraisons.

## Termes sur la priorité et les délais

Priorité
:   Le niveau d'urgence du ticket : <span class="ui">Basse</span>, <span class="ui">Moyenne</span>, <span class="ui">Élevée</span> ou <span class="ui">Critique</span>. Vous choisissez entre <span class="ui">Basse</span>, <span class="ui">Moyenne</span> et <span class="ui">Élevée</span> ; le support peut la modifier.

Critique
:   La priorité la plus haute. Elle est réservée au support, qui l'attribue par exemple en cas de fraude, de problème de sécurité ou de problème financier grave.

C'est urgent
:   La case à cocher qui signale au support que votre demande est grave. Elle ne rend pas le ticket critique automatiquement : le support décide.

SLA
:   De l'anglais *Service Level Agreement*, « engagement de niveau de service ». Ce sont les délais que le support se fixe pour répondre à votre ticket et pour le résoudre. Ils dépendent de la priorité et sont comptés tous les jours, 24 h/24 et 7 j/7, week-ends et jours fériés compris.

## Termes sur les statuts

Statut
:   L'étape où en est votre ticket. C'est le support qui le fait évoluer.

Nouveau
:   Le ticket vient d'être créé et n'est pas encore attribué à un agent.

Attribué
:   Un agent support a pris le ticket en charge.

En cours
:   Le support travaille sur votre demande.

En attente du client
:   Le support attend une information de votre part. Répondez dans la conversation pour que le traitement reprenne.

Résolu
:   Le support considère que le problème est réglé. Vous pouvez encore demander la réouverture.

Fermé
:   Le ticket est terminé définitivement. Il ne peut plus être rouvert : créez un nouveau ticket si besoin.

## Termes sur les échanges et le suivi

Conversation
:   Les messages échangés entre vous et le support dans un ticket. Votre description est le premier message.

Pièce jointe
:   Un fichier ajouté à un ticket ou à un message : JPG, JPEG, PNG, WEBP ou PDF, 10 Mo au maximum par fichier.

Suivi du ticket
:   La liste datée des étapes importantes de votre ticket : création, changements de statut, messages, réouverture.

Notification
:   Un avertissement qui vous signale un événement sur un de vos tickets, par exemple une nouvelle réponse du support.

Demande de réouverture
:   Votre demande pour que le support reprenne un ticket <span class="ui">Résolu</span> dont le problème n'est pas réglé. Le support l'accepte ou la refuse.

Résolution
:   L'étape où le support considère que le problème est réglé : le ticket passe <span class="ui">Résolu</span>.

Fermeture
:   L'étape finale d'un ticket : le ticket passe <span class="ui">Fermé</span>.

## Termes sur l'application

Compte Maplenou
:   Le compte avec lequel vous vous connectez : le même numéro de téléphone et le même mot de passe que dans l'application Maplenou. Votre nom, votre profil et vos coordonnées en viennent.

Préférences
:   La langue et le thème de l'application, dans la page <span class="ui">Compte</span>.

Thème
:   Les couleurs de l'application : <span class="ui">Système</span>, <span class="ui">Clair</span> ou <span class="ui">Sombre</span>.

Centre d'aide
:   Ce guide. Le lien <span class="ui">Centre d'aide</span> de l'application l'ouvre dans un nouvel onglet.

FCFA
:   Le franc CFA, la monnaie utilisée pour les montants des commandes.
