# Premiers pas

Cette page explique comment ouvrir l'application du service client, vous connecter et vous repérer dans les écrans.

## Ouvrir l'application du service client

Le service client Maplenou s'utilise dans un navigateur web, sur ordinateur comme sur téléphone. Ouvrez l'adresse de l'application que Maplenou vous a communiquée.

Des applications mobiles Maplenou pourront aussi donner accès au service client. Le fonctionnement décrit dans ce guide reste le même.

## Se connecter avec son compte Maplenou

Seules les personnes connectées peuvent créer un ticket. Vous utilisez votre **compte Maplenou** habituel : le même numéro de téléphone et le même mot de passe que dans l'application Maplenou. Il n'y a pas de compte séparé pour le service client.

1. Sur la page <span class="ui">Connexion</span>, saisissez votre <span class="ui">Numéro de téléphone</span> avec l'indicatif, par exemple +228 90 00 00 00.
2. Saisissez votre <span class="ui">Mot de passe</span>, puis cliquez sur <span class="ui">Se connecter</span>.
3. Si la vérification en deux étapes est activée sur votre compte, l'écran <span class="ui">Vérification en deux étapes</span> s'affiche. Saisissez le <span class="ui">Code de vérification</span> à 6 chiffres affiché par votre application d'authentification, puis cliquez sur <span class="ui">Valider</span>. Le bouton <span class="ui">Revenir</span> ramène à l'étape du mot de passe.
4. L'écran d'aide s'ouvre.

Votre nom, votre profil (client, vendeur ou livreur) et vos coordonnées viennent de votre compte Maplenou. Le support sait donc qui vous êtes : vous n'avez pas à le préciser dans vos tickets.

!!! warning "Session expirée"
    Après un certain temps, votre session se termine. L'écran de connexion s'affiche alors avec le message <span class="ui">Votre session a expiré. Reconnectez-vous.</span> Connectez-vous de nouveau pour continuer.

## Résoudre un problème de connexion

| Message affiché | Que faire |
| --- | --- |
| <span class="ui">Numéro de téléphone ou mot de passe incorrect.</span> | Vérifiez le numéro (avec l'indicatif) et le mot de passe : ce sont ceux de l'application Maplenou. |
| <span class="ui">Code de vérification incorrect ou expiré.</span> | Saisissez le nouveau code affiché par votre application d'authentification. |
| <span class="ui">La vérification a expiré. Recommencez la connexion.</span> | Cliquez sur <span class="ui">Revenir</span> et saisissez de nouveau votre mot de passe. |
| <span class="ui">Trop de tentatives. Réessayez dans quelques minutes.</span> | Attendez quelques minutes avant de réessayer. |
| <span class="ui">Ce compte est désactivé. Contactez le support Maplenou.</span> | Votre compte Maplenou ne peut pas se connecter : contactez Maplenou. |
| <span class="ui">Le service de connexion Maplenou est momentanément indisponible. Réessayez.</span> | Réessayez un peu plus tard. |

**Mot de passe oublié ?** Le service client ne permet pas de le changer : réinitialisez-le depuis l'application Maplenou, puis connectez-vous ici avec le nouveau mot de passe.

## Se connecter à la version de démonstration

La version de démonstration permet de découvrir le service client avec des données d'exemple. Elle affiche la page <span class="ui">Connexion de démonstration</span> au lieu de la connexion Maplenou.

1. Ouvrez l'application de démonstration.
2. Dans la section <span class="ui">Demandeurs (application client, vendeur, livreur)</span>, cliquez sur un profil.
3. L'écran d'aide de ce profil s'ouvre.

Chaque profil affiche son nom et son rôle (<span class="ui">Client</span>, <span class="ui">Vendeur</span> ou <span class="ui">Livreur</span>). Pour essayer un autre rôle, déconnectez-vous puis choisissez un autre profil.

## Découvrir l'écran d'aide

Après la connexion, vous arrivez sur l'écran d'aide. Son titre dépend de votre profil :

| Profil | Titre de l'écran | Bouton principal |
| --- | --- | --- |
| Client | <span class="ui">Aide et assistance</span> | <span class="ui">Créer un ticket</span> |
| Vendeur | <span class="ui">Support vendeur</span> | <span class="ui">Créer un ticket</span> |
| Livreur | <span class="ui">Support livraison</span> | <span class="ui">Signaler un incident</span> |

L'écran contient :

- un message d'accueil à votre nom ;
- le bouton pour **créer un ticket** (ou **signaler un incident** pour un livreur) ;
- le bouton <span class="ui">Mes tickets</span> pour voir toutes vos demandes ;
- le bloc <span class="ui">Demandes en cours</span>, avec vos derniers tickets ouverts et le lien <span class="ui">Tout voir</span> (il n'apparaît que si vous avez des tickets ouverts) ;
- la liste des <span class="ui">Catégories</span> : cliquez sur une catégorie pour créer un ticket avec cette catégorie déjà choisie.

## Se déplacer avec la barre de navigation

En bas de l'écran, la barre de navigation est toujours visible. Elle contient quatre entrées :

| Entrée | Ce qu'elle ouvre |
| --- | --- |
| <span class="ui">Aide</span> | L'écran d'aide et la création de ticket |
| <span class="ui">Mes tickets</span> | La liste de vos tickets et leur détail |
| <span class="ui">Notifications</span> | Vos notifications ; un compteur rouge indique les notifications non lues |
| <span class="ui">Compte</span> | Vos informations, vos préférences et la déconnexion |

L'entrée de la page où vous vous trouvez est mise en évidence.

## Utiliser l'en-tête sur un grand écran

Sur un ordinateur ou une tablette, l'en-tête en haut de l'écran contient :

- le lien <span class="ui">Centre d'aide</span>, qui ouvre ce guide dans un nouvel onglet ;
- le choix de la langue (`FR` ou `EN`) ;
- le choix du thème ;
- votre nom ;
- le bouton <span class="ui">Déconnexion</span>.

Sur un téléphone, l'en-tête est réduit : il ne garde que le logo et le bouton <span class="ui">Déconnexion</span>. La langue, le thème et le lien vers ce guide se trouvent alors dans la page <span class="ui">Compte</span>.

## Changer la langue et le thème

L'application existe en français et en anglais. Elle propose trois thèmes : <span class="ui">Système</span> (comme votre appareil), <span class="ui">Clair</span> et <span class="ui">Sombre</span>.

- **Sur un grand écran** : utilisez les deux listes de l'en-tête.
- **Sur un téléphone** : ouvrez <span class="ui">Compte</span>, puis la section <span class="ui">Préférences</span>, et choisissez la <span class="ui">Langue</span> et le <span class="ui">Thème</span>.
- **Avant de vous connecter** : la page de connexion (comme la page de connexion de démonstration) propose aussi ces deux choix.

Le changement est immédiat. Votre choix est mémorisé dans ce navigateur. Les détails sont dans [Compte et préférences](account-and-preferences.md).
