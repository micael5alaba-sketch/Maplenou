# UI Design System

Professional, clean, operational, trustworthy, and easy to scan.

## Hierarchy

`Page → Section → Primary information → Secondary information → Actions → Supporting metadata`

## Semantic tokens

Brand, neutral, success, warning, danger, information, focus, typography, spacing, radius, shadow, breakpoint.

Color is never the only status indicator.

## Ticket vocabulary

Statuses: `NEW`, `ASSIGNED`, `IN_PROGRESS`, `WAITING_FOR_CUSTOMER`, `RESOLVED`, `CLOSED`.

Priorities: `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`.

Critical visual prominence does not imply universal edit permission.

## Components

Buttons: Primary, Secondary, Tertiary, Danger, Disabled.

Forms: label, control, helper, validation error.

Communication: Message, Message Composer, Internal Note.

Feedback: Alert, Toast, Empty State, Error State, Loading State, Confirmation Dialog.

Support: SLA Panel, Context Panel, Activity History.

Data: Table, Filter, Pagination.

## Accessibility

WCAG 2.2 is the baseline. Support keyboard navigation, visible focus, labels, semantic headings, logical tab order, readable text, accessible dialogs, and non-color-only status communication.
