# Maplenou Service Client — UX/UI

## CS-02 consolidated baseline

This directory contains the UX/UI baseline for the Maplenou Customer Service and Ticket Management MVP.

CS-02 consolidates user journeys, information architecture, screen inventory, behavior and states, wireframes, design-system guidance, responsive guidance, and prototype scope.

The baseline derives from CS-01 and does not approve a technology stack.

### Deferred MVP scope

AI chatbot, AI-generated replies, predictive classification, sentiment analysis, ML escalation, predictive SLA analytics, and autonomous support decisions remain out of scope.

### Handoff

CS-02 is the UX/UI contract for subsequent technical planning. CS-03 determines the database and backend/API foundation.

Design canvas (Claude Design), in-app design catalogue (`/design`) and screens as built: see [Mockups and screens](screens.md).
