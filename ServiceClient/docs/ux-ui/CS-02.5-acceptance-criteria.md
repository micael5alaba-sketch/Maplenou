# CS-02.5 Acceptance Criteria — Wireframes

- AC-WF-001 Help & Support has clear entry points.
- AC-WF-002 My Tickets exposes essential metadata.
- AC-WF-003 Create Ticket contains approved core fields.
- AC-WF-004 Requester urgency is not direct Critical control.
- AC-WF-005 Requester detail contains conversation, attachments, visible history.
- AC-WF-006 WAITING_FOR_CUSTOMER indicates required action.
- AC-WF-007 RESOLVED exposes reopening request.
- AC-WF-008 CLOSED exposes new-ticket path.
- AC-WF-009 Dashboard exposes operational workload.
- AC-WF-010 Queue exposes essential operational columns.
- AC-WF-011 Support My Tickets exposes personal workload.
- AC-WF-012 Support detail separates internal notes.
- AC-WF-013 SLA is visible in support detail.
- AC-WF-014 Authorized context is separated.
- AC-WF-015 Shared states are represented.
- AC-WF-016 Mobile preserves hierarchy.
- AC-WF-017 Accessibility principles are reflected.
