# CS-02.2 Acceptance Criteria — Information Architecture

- AC-IA-001 Requester navigation provides Aide & Support.
- AC-IA-002 Requester reaches My Tickets and Create Ticket.
- AC-IA-003 Support-only functionality is not exposed as requester functionality.
- AC-IA-004 Support users have Dashboard and Queue according to role.
- AC-IA-005 Ticket information is grouped by purpose.
- AC-IA-006 Internal Notes are separate from visible conversation.
- AC-IA-007 Support navigation respects authorization.
- AC-IA-008 Lifecycle terminology is consistent.
- AC-IA-009 Mobile preserves hierarchy.
- AC-IA-010 Search/filter belongs to support tickets; detailed interaction remains subject to later technical design.
- AC-IA-011 UI navigation does not replace backend authorization.
- AC-IA-012 Breadcrumbs retain clear navigation context.
