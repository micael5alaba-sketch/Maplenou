# Responsive Design

The same information hierarchy applies to mobile, tablet, and desktop.

Mobile collapses dense support information progressively while keeping ticket status, required actions, accessible controls, and logical focus order visible.

Requester path: `Aide & Support → Mes tickets → Ticket`.

Support path: `Tableau de bord → File d'attente / Mes tickets → Ticket`.

Desktop may expose more operational context simultaneously; mobile prioritizes decision-relevant information.
