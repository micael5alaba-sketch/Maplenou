# CS-01 Domain Glossary

**Status:** Approved | **Version:** 1.0.0

| Term | Definition |
| --- | --- |
| Ticket | Support case representing a request, incident, or problem |
| Requester | Customer, seller, or delivery driver initiating the ticket |
| Support Agent | Support worker authorized to process tickets |
| Support Manager | Supervisory support role |
| Administrator | Administrative role |
| Category | Controlled ticket classification |
| Priority | Relative urgency |
| Status | Current ticket lifecycle state |
| Message | Customer-visible communication |
| Internal Note | Support-only communication |
| Ticket History | Audit trail of significant events |
| Assignment | Association between ticket and support agent |
| Contextual Reference | Link to order, payment, seller, delivery, or refund |
| Resolution | State in which the issue has been addressed |
| Closure | Finalization of a ticket |
| Escalation | Transfer to a higher support authority |
| SLA | Service-level expectation for response or resolution |
| First Response | First qualifying support response to the requester |
| SLA Breach | A response or resolution target that has passed without the required action |
| Reopening Request | Request by an authorized requester to have a resolved ticket reconsidered |
